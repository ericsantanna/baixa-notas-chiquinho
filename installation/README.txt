BAIXA NOTAS CHIQUINHO - INSTRUÇÕES DE INSTALAÇÃO

1. Execute o arquivo "install.bat" APENAS UMA VEZ
   (Isso criará um ícone na sua área de trabalho)

2. Use o ícone "Baixa Notas Chiquinho" na área de trabalho para executar o programa

3. Quando executar, abra seu navegador e vá para: http://localhost:8080

IMPORTANTE: Mantenha esta pasta completa, não mova ou delete nenhum arquivo!
